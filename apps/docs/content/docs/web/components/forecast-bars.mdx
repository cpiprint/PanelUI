Use it for a handful of values where one is in focus: a week of forecasts with today picked, six months with the current one picked. Pressing a bar picks it, and you show that bar's figure beside the row.

It behaves as a row of radio buttons, so exactly one bar is always picked.

Seven bars this size cannot be compared to the percent. For values someone has to read precisely, or for more than about twelve of them, use a chart with an axis.

## Usage

```tsx
import { ForecastBars, type ForecastBar } from "@/components/panelui/forecast-bars"
```

```tsx
const week: ForecastBar[] = [
  { label: 'S', name: 'Sunday', value: 22 },

  { label: 'T', name: 'Tuesday', value: 14 },
```

## Examples

### Its own scale

Without `max` the tallest bar fills its track and the rest are drawn against it. `defaultValue` picks a bar to begin with and lets the component hold the choice.

## API Reference

### ForecastBars

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `data` | `ForecastBar[]` | — | The bars, left to right. |
| `max` | `number` | — | The value a full bar stands for. Defaults to the largest in `data`. |
| `value` | `number` | — | The index of the picked bar, when the caller holds it. |
| `defaultValue` | `number` | `0` | The index picked to begin with, when the caller does not hold it. |
| `onValueChange` | `(index: number) => void` | — | Called with the index of a bar when it is picked. |
| `formatValue` | `(value: number) => string` | `(bar) => String(bar)` | Writes a value for a screen reader: "78 percent". |
| `label` | `string` | `'Forecast'` | What a screen reader calls the row. |

Every part also takes the props of the element it renders, and a `className`.

## Notes

### Scale

A bar's height is its value divided by `max`, measured from the bottom of its track. Set `max` when the values share a known ceiling, such as 100 for a percentage. Leave it out to scale to the largest value in `data`.

The scale always starts at zero. A value above `max` fills the track and goes no further.

### Labels

`label` is drawn under the bar and should be short. `name` is the long form a screen reader is given, with the value: "Thursday: 78 percent". Use `formatValue` to say the unit.

### Keyboard

The row is one Tab stop. Left and right move the pick and wrap at the ends, Home and End go to the first and last bar.

### Motion

The bars grow from empty when the component mounts, and a bar changes height smoothly when its value changes. With reduced motion on, both happen at once.

### Colour

The picked bar is the accent at full strength and the others are the same gradient, dimmed. Set `--panelui-accent` to change it.
