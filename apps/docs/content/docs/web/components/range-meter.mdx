Use it for one reading that only means something next to its range: a heart rate between the day's lowest and its peak, a goal between a floor and a ceiling. The value is written on the thumb, so where it is and what it is are read together.

With `onValueChange` it is a slider you can drag. Without it, it is a meter that shows a value.

It holds one value. For two ends of a range, or a control in a form where the number matters less than the label, use a slider.

## Examples

### A meter

Leave out `onValueChange` and it cannot be moved. `formatValue` writes the number on the thumb, here with its unit. The accent is the `--panelui-accent` variable, set on the meter in this example.

<ComponentPreview name="range-meter/reading" height={280}>

```tsx
'use client';

import { DropletIcon } from 'lucide-react';
import { RangeMeter } from '@/components/panelui/range-meter';

/** No `onValueChange`, so it shows a value and cannot be moved. */
export default function RangeMeterReading() {
  return (
    <div className="dark flex w-full max-w-md flex-col gap-4 rounded-[28px] bg-card p-6 text-card-foreground">
      <div className="flex items-baseline justify-between">
        <p className="text-muted-foreground">Water today</p>
        <p className="text-sm text-muted-foreground">Goal 2.5 L</p>
      </div>
      <RangeMeter
        min={0}
        max={2.5}
        value={1.8}
        marker={2}
        label="Water today"
        valueText="1.8 of 2.5 litres"
        formatValue={(litres) => `${litres} L`}
        // Any colour works as the accent. It is one variable.
        className="[--panelui-accent:oklch(0.72_0.14_230)]"
      >
        <DropletIcon fill="currentColor" />
      </RangeMeter>
    </div>
  );
}
```

### Steps and a format

`step` is what a drag snaps to and what one arrow key press moves by. A long number is shortened on the thumb with `formatValue`, and `valueText` gives a screen reader the whole figure.

<ComponentPreview name="range-meter/steps" height={300}>

```tsx
'use client';

import { FootprintsIcon } from 'lucide-react';
import { useState } from 'react';
import { RangeMeter } from '@/components/panelui/range-meter';

const compact = new Intl.NumberFormat('en-US', { notation: 'compact', maximumFractionDigits: 1 });

export default function RangeMeterSteps() {
  const [goal, setGoal] = useState(8000);

  return (
    <div className="dark flex w-full max-w-md flex-col gap-4 rounded-[28px] bg-card p-6 text-card-foreground">
      <div className="flex items-baseline justify-between">
        <p className="text-muted-foreground">Daily step goal</p>
        <p className="text-sm text-muted-foreground">About {Math.round(goal / 1300)} km</p>
      </div>
      <RangeMeter
        min={2000}
        max={14000}
        step={500}
        value={goal}
        onValueChange={setGoal}
        label="Daily step goal"
        valueText={`${goal.toLocaleString('en-US')} steps`}
        formatValue={(steps) => compact.format(steps)}
      >
        <FootprintsIcon />
      </RangeMeter>
      <div className="flex justify-between text-sm text-muted-foreground">
        <span>2k</span>
        <span>14k</span>
      </div>
    </div>
  );
}
```

</ComponentPreview>

## API Reference

### RangeMeter

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `min` | `number` | `0` | The low end of the track. |
| `max` | `number` | `100` | The high end of the track. |
| `value` | `number` | — | The reading: where the thumb sits and the number written on it. |
| `onValueChange` | `(value: number) => void` | — | Called with the new value as the thumb is dragged or moved with the keyboard. Passing this makes it a slider; without it, it is a meter. |
| `step` | `number` | `1` | How much one arrow key press moves the value, and what a drag snaps to. |
| `marker` | `number` | — | A value to mark on the track with a dashed line, such as an average. |
| `formatValue` | `(value: number) => ReactNode` | — | Writes the number on the thumb. Defaults to the value as it is. |
| `label` | `string` | `'Reading'` | What a screen reader calls it. |
| `valueText` | `string` | — | What a screen reader says for the value: "89 beats per minute". |

Every part also takes the props of the element it renders, and a `className`.

## Notes

### The marker

`marker` draws a dashed line at a value on the track: an average, a goal, yesterday's reading. It is decoration and is not announced, so say what it marks in the text around the meter.

### Keyboard

As a slider it takes focus. Left and right move by `step`, Page Up and Page Down by a tenth of the range, Home and End go to the ends.

### Screen readers

It is announced as a slider or a meter with its value, minimum and maximum. Pass `valueText` when the bare number is not enough: "89 beats per minute" in place of "89".

### The thumb near the ends

The thumb is held in from each end of the track by half its own width, so at the lowest and highest values it stays inside the meter. The gradient still deepens at the true position.

### Colour

The track and thumb use the accent, deepened towards red under the thumb. Set `--panelui-accent` on the meter or on any ancestor to change it. The number on the thumb is white, so pick an accent dark enough to read it against.
