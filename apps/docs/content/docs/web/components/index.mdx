Every page opens on the component running. Press **Code** on any preview for the source of what
you are looking at.

<Cards>
  <Card title="Activity Grid" href="/docs/web/components/activity-grid">
    A period as a grid of pills: each day met, partly met or missed.
  </Card>
  <Card title="Feedback" href="/docs/web/components/feedback">
    A dialog with a well to write in and two actions in the band around it.
  </Card>
  <Card title="Forecast Bars" href="/docs/web/components/forecast-bars">
    A short run of values as capsule bars, one of them picked.
  </Card>
  <Card title="Planet" href="/docs/web/components/planet">
    The world as dots on a globe you can turn, with markers pinned to it.
  </Card>
  <Card title="Range Meter" href="/docs/web/components/range-meter">
    A reading on a track between its lowest and highest, with the number on the thumb.
  </Card>
  <Card title="Rolling Number" href="/docs/web/components/rolling-number">
    A number whose digits roll to their new values.
  </Card>
  <Card title="Stat Strip" href="/docs/web/components/stat-strip">
    A row of figures, each over the words that say what it is.
  </Card>
</Cards>
