Use it for a few related cards where one is being read and the others should stay in reach: several readings of the same thing, the steps of a short flow. The open item is a card. The others fold to a single row each and get narrower the further they are from it.

Press a folded item to open it. The one that was open folds in its place.

It is for three or four items. Each folded one still takes a row, so a long list is better as an accordion, and items that are not related are better as tabs.

## Composition

```tsx
<PillStack>
  <PillStack.Item value="…">
    <PillStack.Pill>…</PillStack.Pill>
    <PillStack.Panel>…</PillStack.Panel>
  </PillStack.Item>
</PillStack>
```

- **`PillStack.Item`** — One card. Its `value` is how the stack refers to it. Items must be direct children of `PillStack`.
- **`PillStack.Pill`** — What the item shows while folded: one row, and the button that opens it.
- **`PillStack.Panel`** — What it shows while open. `className` goes on the padded inner box.

## Examples

### Moving it from inside

Hold `value` yourself and anything can change which item is open. Here the buttons in each panel step through a short flow, and the items take a border to sit on a light page.

```tsx
'use client';

import { useState } from 'react';
import { Button } from '@/components/ui/button';
import { PillStack } from '@/components/panelui/pill-stack';

const STEPS = [
  {
    id: 'account',
    title: 'Create your account',
    body: 'An email address and a password. You can add a team later.',
  },
  {
    id: 'project',
    title: 'Name your first project',
    body: 'A project holds the feedback for one app. Most teams start with one.',
  },
  {
    id: 'install',
    title: 'Install the SDK',
    body: 'One package and one key. The quickstart takes about five minutes.',
  },
];

export default function PillStackSteps() {
  // Held here, so the buttons inside each panel can move the stack on.
  const [step, setStep] = useState('account');

  return (
    <PillStack value={step} onValueChange={setStep} className="max-w-md">
      {STEPS.map((item, position) => (
        <PillStack.Item key={item.id} value={item.id} className="border">
          <PillStack.Pill className="px-6">
            <span className="flex size-8 shrink-0 items-center justify-center rounded-full bg-foreground/10 text-sm font-medium tabular-nums">
              {position + 1}
            </span>
            <span className="min-w-0 flex-1 truncate font-medium">{item.title}</span>
          </PillStack.Pill>
          <PillStack.Panel className="flex flex-col gap-4">
            <div className="flex flex-col gap-1.5">
              <p className="text-sm text-muted-foreground">
                Step {position + 1} of {STEPS.length}
              </p>
              <h3 className="text-xl font-semibold">{item.title}</h3>
              <p className="text-muted-foreground">{item.body}</p>
            </div>
            <div className="flex gap-2">
              {position > 0 ? (
                <Button variant="outline" size="sm" onClick={() => setStep(STEPS[position - 1].id)}>
                  Back
                </Button>
              ) : null}
              {position < STEPS.length - 1 ? (
                <Button size="sm" onClick={() => setStep(STEPS[position + 1].id)}>
                  Continue
                </Button>
              ) : null}
            </div>
          </PillStack.Panel>
        </PillStack.Item>
      ))}
    </PillStack>
  );
}
```

## API Reference

### PillStack

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `string` | — | The `value` of the open item, when the caller holds it. |
| `defaultValue` | `string` | — | The item open to begin with, when the caller does not hold it. |
| `onValueChange` | `(value: string) => void` | — | Called with an item's `value` when its pill is pressed. |

### PillStack.Item

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `string` | — | What identifies this item to `value` and `onValueChange`. |

Every part also takes the props of the element it renders, and a `className`.

## Notes

### Which item is open

Exactly one. `defaultValue` chooses it to begin with, or `value` and `onValueChange` let you hold it. With neither, the last item is open, which puts the card at the foot of the stack with the pills above it.

### Order

Items stay in the order you write them. Opening one does not move it: it grows where it is, and the widths of the others change with their distance from it.

### Surface

Each item is `bg-card`. On a page of the same colour it has no edge, so give the items a `border` or a shadow with `className`, or put the stack on a contrasting background.

### Height

The stack changes height when an item opens, since a panel is taller than a pill. Leave room below it, or give its container a `min-height`, so the content under it does not jump.

### Keyboard and screen readers

Each pill is a button that reports whether its panel is expanded. A folded panel cannot be tabbed into, and neither can the pill of the open item, since both are hidden.

### Motion

Opening and folding take half a second. With reduced motion on, the change is immediate.

### Server Components

`PillStack` is a client component. In a file that starts with `"use client"`, write its parts with a dot, as on this page. A Server Component cannot read `PillStack.Item` off the import, so each part is also exported by name: `PillStackItem` is `PillStack.Item`, and so on for the others.

```tsx
import { PillStack, PillStackItem, PillStackPill, PillStackPanel } from "@/components/panelui/pill-stack"
```
