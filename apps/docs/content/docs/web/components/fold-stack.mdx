Use it for a few readings or steps where one is looked at in full and the rest only need a line each: the vital signs of a service, the steps of a setup. Each item is one row with an icon, a name and a figure. Pressing a row opens it out into its card, and the one that was open folds back to a row.

Exactly one item is always open. The folded rows get narrower the further they are from it.

For sections that can all be closed, or several open at once, use an accordion. Past about five items the narrowing runs out, and a list is the better shape.

## Composition

```tsx
<FoldStack>
  <FoldStack.Item value="…">
    <FoldStack.Summary icon={…} value="…">…</FoldStack.Summary>
    <FoldStack.Panel>…</FoldStack.Panel>
  </FoldStack.Item>
</FoldStack>
```

- **`FoldStack.Item`** — One item. `value` identifies it and `color` is the theme role its tile and lights are drawn in. Items have to be direct children of the stack.
- **`FoldStack.Summary`** — The folded form, and the button that opens the item. `icon` goes in the tile, the children are the name, `value` is the figure at the end and `level` lights up to four small bars after it.
- **`FoldStack.Panel`** — The open form: the card's contents. Anything can go in it, another component included.

## Examples

### Holding the open item yourself

`value` and `onValueChange` put the open item in your own state, so a button inside one card can open the next. A summary's `value` can be any short text, here the step's number.

<ComponentPreview name="fold-stack/steps" height={420}>

```tsx
'use client';

import { BellIcon, GitBranchIcon, UsersIcon } from 'lucide-react';
import { useState } from 'react';
import { Button } from '@/components/ui/button';
import { FoldStack } from '@/components/panelui/fold-stack';

const STEPS = [
  {
    id: 'invite',
    icon: <UsersIcon />,
    title: 'Invite your team',
    body: 'Anyone with an address at your domain can join without being asked twice.',
  },
  {
    id: 'connect',
    icon: <GitBranchIcon />,
    title: 'Connect a repository',
    body: 'Read access is enough to start. Write access is only needed for automatic fixes.',
  },
  {
    id: 'notify',
    icon: <BellIcon />,
    title: 'Choose where alerts go',
    body: 'One channel for failures is usually plenty. You can split them up later.',
  },
];

export default function FoldStackSteps() {
  const [step, setStep] = useState(STEPS[0].id);

  return (
    <FoldStack value={step} onValueChange={setStep} className="max-w-sm">
      {STEPS.map((entry, index) => (
        <FoldStack.Item key={entry.id} value={entry.id}>
          <FoldStack.Summary icon={entry.icon} value={`${index + 1}/${STEPS.length}`}>
            {entry.title}
          </FoldStack.Summary>
          <FoldStack.Panel className="flex flex-col items-start gap-2">
            <p className="text-xs font-medium text-muted-foreground">
              Step {index + 1} of {STEPS.length}
            </p>
            <h3 className="text-lg font-semibold tracking-tight">{entry.title}</h3>
            <p className="text-sm text-muted-foreground">{entry.body}</p>
            {index < STEPS.length - 1 ? (
              <Button size="sm" className="mt-2" onClick={() => setStep(STEPS[index + 1].id)}>
                Continue
              </Button>
            ) : (
              <Button
                size="sm"
                variant="outline"
                className="mt-2"
                onClick={() => setStep(STEPS[0].id)}
              >
                Start again
              </Button>
            )}
          </FoldStack.Panel>
        </FoldStack.Item>
      ))}
    </FoldStack>
  );
}
```

## API Reference

### FoldStack

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `string` | — | The `value` of the open item, when the caller holds it. |
| `defaultValue` | `string` | — | The item open to begin with, when the caller does not hold it. Defaults to the first. |
| `onValueChange` | `(value: string) => void` | — | Called with an item's `value` when it is opened. |

### FoldStack.Item

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `string` | — | What identifies this item to `value` and `onValueChange`. |
| `color` | `FoldStackColor` | `primary` | One of the theme's roles for the item's tile and lights. |

### FoldStack.Summary

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `icon` | `ReactNode` | — | Drawn in the tile at the start of the row. |
| `value` | `ReactNode` | — | The figure at the end of the row. |
| `level` | `number` | — | How high the figure is on its own scale, from 0 to 1. Drawn as four lights after the figure. Leave it out for a row without them. |

Every part also takes the props of the element it renders, and a `className`.

## Notes

### Which item is open

`defaultValue` names the item open to begin with. Without it, or if it names no item, the first one is open.

### Summary and panel are two views of one thing

The summary is not a header that stays above the panel. When an item opens its summary goes and the panel takes its place, so put the name and the figure in the panel as well, at whatever size the card wants them.

### The lights

`level` is how high the figure is on its own scale, from 0 to 1, and is drawn as four bars of rising height with that share of them lit. It is a rough reading for comparing rows at a glance. Leave it out and the row ends at the figure.

### Widths

The open item is the full width of the stack. Each step away from it an item is 8 percent narrower, down to 76 percent.

### Colour

`color` on an item tints the tile behind its icon and lights its bars. It defaults to `primary`, the theme's neutral. Use the status colours when the colour says something.

### Contents stay mounted

A folded item's panel stays in the page, so a field somebody filled in is still filled when it opens again. Whichever of the summary and the panel cannot be seen is made inert.

### Keyboard

Each folded row is a button: Tab moves between them and Enter or Space opens one.

### Motion

Opening an item grows its row into the card and changes the widths over half a second. With reduced motion on, it happens at once.

### Server Components

`FoldStack` is a client component. In a file that starts with `"use client"`, write its parts with a dot, as on this page. A Server Component cannot read `FoldStack.Item` off the import, so each part is also exported by name: `FoldStackItem` is `FoldStack.Item`, and so on for the others.

```tsx
import { FoldStack, FoldStackItem, FoldStackSummary, FoldStackPanel } from "@/components/panelui/fold-stack"
```
