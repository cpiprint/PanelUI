Use it for a few things of the same kind where one is looked at at a time and it helps to see that there are more: the stages of a pipeline, the steps of a setup, a handful of plans. It is a deck of cards. One is in front, the next two show as edges under it, and a row of tabs brings any card forward.

The deck is as tall as its tallest card and stays that height, so nothing under it moves when the card changes.

Every card has to fit that one size. For sections of very different lengths use an accordion, and past about six cards the row of tabs wraps and a list is the better shape.

## Composition

```tsx
<FoldStack>
  <FoldStack.Item value="…" label="…">…</FoldStack.Item>
</FoldStack>
```

- **`FoldStack.Item`** — One card, and its tab. `value` identifies it, `label` is what the tab says, and `color` is the light on the tab. Its children are the card's contents. Items have to be direct children of the stack.

## Examples

### Holding the front card yourself

`value` and `onValueChange` put the front card in your own state, so a button inside one card can bring the next forward.

<ComponentPreview name="fold-stack/one-at-a-time" height={400}>

```tsx
'use client';

import { useState } from 'react';
import { Button } from '@/components/ui/button';
import { FoldStack } from '@/components/panelui/fold-stack';

const STEPS = [
  {
    id: 'invite',
    tab: 'Invite',
    title: 'Invite your team',
    body: 'Anyone with an address at your domain can join without being asked twice.',
  },
  {
    id: 'connect',
    tab: 'Connect',
    title: 'Connect a repository',
    body: 'Read access is enough to start. Write access is only needed for automatic fixes.',
  },
  {
    id: 'notify',
    tab: 'Notify',
    title: 'Choose where alerts go',
    body: 'One channel for failures is usually plenty. You can split them up later.',
  },
];

export default function FoldStackOneAtATime() {
  const [step, setStep] = useState(STEPS[0].id);

  return (
    <FoldStack value={step} onValueChange={setStep} label="Setup steps" className="max-w-sm">
      {STEPS.map((entry, index) => (
        <FoldStack.Item key={entry.id} value={entry.id} label={entry.tab}>
          <div className="flex h-full flex-col items-start gap-2">
            <p className="text-xs font-medium text-muted-foreground">
              Step {index + 1} of {STEPS.length}
            </p>
            <h3 className="text-lg font-semibold tracking-tight">{entry.title}</h3>
            <p className="text-sm text-muted-foreground">{entry.body}</p>
            {index < STEPS.length - 1 ? (
              <Button size="sm" className="mt-2" onClick={() => setStep(STEPS[index + 1].id)}>
                Continue
              </Button>
            ) : (
              <Button
                size="sm"
                variant="outline"
                className="mt-2"
                onClick={() => setStep(STEPS[0].id)}
              >
                Start again
              </Button>
            )}
          </div>
        </FoldStack.Item>
      ))}
    </FoldStack>
  );
}
```

## API Reference

### FoldStack

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `string` | — | The `value` of the card in front, when the caller holds it. |
| `defaultValue` | `string` | — | The card in front to begin with, when the caller does not hold it. Defaults to the first. |
| `onValueChange` | `(value: string) => void` | — | Called with a card's `value` when it is brought to the front. |
| `label` | `string` | `'Cards'` | What a screen reader calls the row of tabs. |

### FoldStack.Item

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `string` | — | What identifies this card to `value` and `onValueChange`. |
| `label` | `ReactNode` | — | What its tab says. Defaults to the `value`. |
| `color` | `FoldStackColor` | — | One of the theme's roles for the light on its tab. |

Every part also takes the props of the element it renders, and a `className`.

## Notes

### Which card is in front

`defaultValue` names the card in front to begin with. Without it, or if it names no card, the first one is.

### The pile

The two cards after the front one show under it, each 6 percent smaller and 12px lower than the card before, and a shade further back. The order goes round: behind the last card is the first. Any further cards are hidden until they come within two of the front.

Pressing the edge of a card behind brings that card forward, which is a quick way to the next one.

### Height

All the cards share one size, the height of the tallest. A short card is stretched to it, so give a card's contents `h-full` if something in it should sit at the bottom.

### Colour

`color` on an item is the small light on its tab, in one of the theme's roles. It defaults to `primary`. Use the status colours when the colour says something, such as the state of a stage.

### Contents stay mounted

The cards behind stay in the page, so a field somebody filled in is still filled when its card comes back. They are made inert and hidden from screen readers while they are behind.

### Keyboard

The row of tabs is one Tab stop. Left and right move to the next tab and bring its card forward, wrapping at the ends, and Home and End go to the first and last.

### Motion

Changing the card moves each one to its new place in the pile over half a second. With reduced motion on, it happens at once.

### Server Components

`FoldStack` is a client component. In a file that starts with `"use client"`, write its parts with a dot, as on this page. A Server Component cannot read `FoldStack.Item` off the import, so each part is also exported by name: `FoldStackItem` is `FoldStack.Item`.

```tsx
import { FoldStack, FoldStackItem } from "@/components/panelui/fold-stack"
```
